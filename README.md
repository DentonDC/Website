# Denton

Одностраничная визитка: статический сайт без сборки. Корень сайта — эта папка.

## Как открыть локально

Откройте `index.html` в браузере (двойной клик или «Файл → Открыть»).

Если нужен HTTP-сервер, запустите любой статический сервер из корня проекта и откройте выданный им адрес. Команда сборки не требуется.

## Деплой

Сайт публикуется на **Cloudflare Pages**.

- Корень проекта = выходная директория
- Команда сборки не нужна
- Картинки лежат в `/assets`
