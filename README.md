# Denton

Одностраничная визитка и кабинет родительского комитета. Корень сайта — эта папка, сборка не нужна.

## Как открыть локально

Откройте `index.html` в браузере или поднимите любой статический сервер из корня проекта.

Кабинет: `committee/`. Пока не подключена Cloudflare D1, данные хранятся в браузере этого устройства.

## Деплой

Сайт публикуется на **Cloudflare**. Команда сборки не нужна, выходная директория — корень репозитория.

- Картинки лежат в `/assets`
- API лежит в `/functions/api` и отвечает по `/api/*`

Не кладите в корень `wrangler.toml` с `pages_build_output_dir = "."`: из‑за этого Workers Builds падает.

## Общая база (Cloudflare D1)

Чтобы сборы, касса и объявления были общими для всех родителей:

1. В Cloudflare создайте базу D1 с именем `committee`.
2. Привяжите её к проекту как binding **`DB`**.
3. Схему создавать вручную не нужно: таблицы появятся при первом запросе к API.
